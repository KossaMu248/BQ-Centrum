# Stage16 NPC source-pose rendering and child scale

The actual active child cast is `BearlyKids`: bottle/rock/firecracker use original `teen-molotov-poses-v18.png`, `teen-rock-poses-v18.png`, `teen-firecracker-poses-v18.png`, `teen-run-opposites-v18.png` and `teen-screen-v18.png`. No art is generated, replaced, recoloured or converted. The child world-height reference changes120→94 against the unchanged adult128 reference, uniformly across idle, running, combat/reaction, prone and thrown-screen states. Source outfits and identities remain. The existing release-hand calculation now receives the same94 height; damage, duration/range and attack rules are unchanged. Warning captions and neighbourhood audit use the same child scale.

The target adult renderer explicitly opts into complete existing source walking paintings. Variants0–8 share source units and use `[walkA,idle,walkB,idle]`; civilian9–11 use their two complete walking paintings, avoiding pulse between separately authored idle/walk source units. The opaque sole from the actual pose's metadata is aligned to the same world floor. Each walking NPC submits one whole source image: no half-body rotations, mesh-folded X legs, cropped shoe slivers, duplicate person overlay, new bitmaps or per-frame pixel reads. This is a deliberately limited classic key-frame cycle, not newly drawn animation or a promise of continuous per-pixel foot locking.

Original default `NpcMotion.preloadAll` and compiled48-frame API remain available. The target BrawlArt call and scene preparation opt into source-only walking and skip those unused deformation banks. The legacy cache's distance cycle was also corrected from.72h to2×.17h/.62 to match its planted-sole math; that cadence check is separate from the limited whole-pose cycle.

Target movement allocates0 walk-frame canvases and0 walk-bank bytes; explicit legacy preload still warms48 frames for the requested variant. Scene-specific coalescing, validation/retry and identity/no-save-write tests also pass. These mocked-pixel contracts do not prove appearance.

They show all12 adult identities at height128 in four phase samples and all3 child types at height94 through idle/runA–D. The boards use the current source files while the broader Stage16 integration was still in progress; exact hashes/build are recorded.

Actual source-street/Centrum gameplay, motion, performance, peaceful rest and camera checks are reported separately by the full stage. Existing source idle/walk paintings have only a few keys; the cycle remains visibly keyed, especially the two-key civilian walk. Original baby/player renderers and all original source cache assets are untouched by this NPC change.
